Claude Code plugin

mg-harness

Claude Code skills & harness rituals for engineering leaders.

Code is the easy part. A leader's job is wider — operational queues, communication, decisions, multi-week initiatives spanning dozens of sessions. mg-harness shapes Claude around that wider job: small, opinionated, built to make your week less reactive.

Two surfaces, one install

Add the marketplace and install once. Two kinds of capability show up in your sessions.

Skills

Auto-triggered expertise

You describe what you want; the right skill loads itself. No commands to memorize — Claude triggers them by intent.

  • Coding discipline that resists scope creep
  • Linear triage & engineer handoffs
  • A scheduled morning briefing
Harness

Reliable multi-session work

Six slash commands, five lifecycle hooks, and three subagents that turn a single chat into a durable, resumable workflow.

  • State files re-read on every session start
  • Structured handoffs at every compaction
  • A verification gate before work ships

Built to fix real failure modes

Each skill and ritual exists because of a specific way applying a coding agent across the whole job breaks down.

01

The agent overbuilds

A small ask becomes a sprawling diff — adjacent code "improved," speculative abstractions added. Discipline loads before the first line is written.

karpathy-coding-guidelines
02

Triage eats your week

The mechanical half of triage is solved; the judgment half burns calendar time. This layers on top of Linear's native triage, not in place of it.

linear-triage-automation
03

Signal is scattered

Hundreds of unread items across Slack, Teams, and email. A scheduled task does the synthesis before you sit down each morning.

morning-briefing
04

Handoffs lose context

Reassigned tickets arrive with a one-line comment and the new owner pays the tax. Context becomes the precondition for reassignment.

linear-handoff
05

Multi-session work loses state

The biggest work doesn't fit in one chat. You hit the context limit, stop for the day, and re-derive everything next time. The full harness — state files, structured handoffs, drift detection, and verification gates — makes the discipline automatic instead of relying on memory.

the harness state-discipline

What's inside

Five skills, plus the harness surfaces — commands, subagents, and hooks under the /mg-harness: namespace.

Skills

karpathy-coding-guidelinesengineering
Minimal diffs, explicit assumptions, verifiable success criteria — pushes back on speculative abstraction and unrequested cleanup.
linear-triage-automationmanagement
Handles the fuzzy half of issue triage — free-text priority parsing, duplicate confirmation, domain inference.
linear-handoffmanagement
Gathers Linear + git/PR state per ticket, drafts a structured handoff comment, posts it before reassigning.
morning-briefingproductivity
A recurring scheduled task that posts a four-section daily rollup: asks, mentions, updates, blockers.
state-disciplineproductivity
Auto-enforces the format of the harness state files when writing to .claude/state/*.

Quickstart

Thirty seconds to install. Two optional config values unlock the verification hooks.

Add the marketplace & install

/plugin marketplace add mgrabovskyi/skills
/plugin install mg-harness@mg-harness

Configure the verification hooks (optional)

/plugin config mg-harness
# set verify_command  e.g. npm run lint --silent
# set test_command    e.g. npm test --silent

Start working

/mg-harness:start-work add JWT validation to the auth service
