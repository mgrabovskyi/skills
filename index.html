Claude Code plugin

mg-harness

A durable Claude Code workflow for long-running, multi-session work.

Code is the easy part. The hard part is work that outlives a single context window — initiatives spanning dozens of chats. mg-harness is the harness for that: state files as the source of truth, planning and review subagents, and lifecycle hooks that keep an agent on-task across sessions. A handful of complementary skills cover the rest of a leader's job.

Running the whole time — automatic, no command needed
📖Session startLoads your state files into context, so you resume — not restart.
📌Every promptRe-anchors the plan, so the agent doesn't drift off-task.
🛂Before each editRuns your verify command; blocks the change if it breaks the build.
📝After each editLogs the change to the changelog automatically.
⏰On stopNudges you to checkpoint if there's unsaved progress.
Files are the source of truth — not chat. State persists across sessions; the conversation is disposable. That single rule is what makes the work durable.
planner — turns a task into an objective and a checklist before any code is written.
reviewer — independent audit: re-runs tests, checks the diff against the plan, verifies claims.
researcher — bounded codebase investigation, dispatched when a question needs digging.

Why a harness, not just skills

mg-harness exists for one failure mode above all. The complementary skills each fix a narrower one.

THE REASON

Multi-session work loses state

The biggest work — strategy, migrations, multi-week initiatives — doesn't fit in one chat. You hit the context limit, stop for the day, and re-derive everything next time: what was decided, what failed, what's left. The harness makes that discipline automatic instead of relying on memory — state files, structured handoffs, drift detection, and a verification gate, all under the /mg-harness: namespace.

Quickstart

Thirty seconds to install. Two optional config values unlock the verification hooks.

Add the marketplace & install

/plugin marketplace add mgrabovskyi/skills
/plugin install mg-harness@mg-harness

Configure the verification hooks (optional)

/plugin config mg-harness
# set verify_command  e.g. npm run lint --silent
# set test_command    e.g. npm test --silent

Start working

/mg-harness:start-work add JWT validation to the auth service
